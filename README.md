Warung Nusantara: a fast, offline cooking game about running an Indonesian street-food stall. Customers order dishes (nasi goreng, mie goreng, sate ayam, bakso, rendang, es teh manis); click the order, assemble the dish at the ingredient stations in recipe order, and serve before patience runs out. Tips, combos, rising difficulty over a 150-second day, all in static HTML/CSS/JS with no network calls.

## Run it

```sh
node main.ts
```

That builds `dossier.json` from `game/` and `screenshots/`. To play, open `game/index.html` in a desktop browser.
